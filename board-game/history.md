# 時代背景：史實查核

問題：遊戲背景能不能放在中世紀？那時候有期貨嗎？

## 結論

中世紀有**遠期合約**，但沒有遊戲核心的那一套：保證金、逐日結算、追繳、強制平倉。

- 13 世紀英格蘭修道院會把未來幾年的羊毛預先賣給義大利商人，期限從幾個月到 20 年，高峰在 1270–1310 年。但買方是**全額預付**，合約不能轉賣，違約時由財政部（Exchequer）扣押修道院財產或重新議定交期，沒有保證金。研究者自己的說法是「forward agreements of sorts rather than futures contracts」（Bell, Brooks & Dryburgh, 2007）。
- 玉米 1493 年才由哥倫布帶進歐洲，原油、天然氣當時也不是交易商品。

所以中世紀可以用，但要換掉商品，保證金機制也只能當成「遊戲上的簡化」。

## 時間軸

| 年代 | 事件 |
|---|---|
| 約公元前 1750 | 漢摩拉比法典第 48 條：天災毀了收成，當年可不還穀物債。這是借貸條款，不是期貨 |
| 公元前 6 世紀 | Thales 預付訂金包下榨油機（Aristotle 記載），近似選擇權 |
| 12–13 世紀 | Champagne 集市：匯票與集市結束時的軋差清算 |
| 約 1270–1310 | 英格蘭修道院羊毛遠期合約的高峰 |
| 1531 | Antwerp 交易所落成，之後出現可轉讓、按差價結算的「to arrive」合約 |
| 1636–37 | 荷蘭鬱金香狂熱，期貨式交易（windhandel）沒有保證金，崩盤後以 3.5% 解約 |
| 1650–1688 | Amsterdam 每季一次的差額結算（rescontre），按市價結算的雛形 |
| 1730 | 大阪堂島米市的帳合米獲幕府承認：有保證金、清算所、定期結算 |
| 1848 / 1865 | 芝加哥期貨交易所（CBOT）成立；1865 年頒布標準化合約與保證金規則 |
| 1871–1895 | 賓州 Titusville、Oil City 的石油交易所交易管線憑證 |
| 1883 / 1925 | CBOT 第一個清算組織 / 中央清算公司 |
| 1974 / 1983 / 1990 | 黃金期貨 / WTI 原油期貨 / 天然氣期貨 |

**最早有保證金、清算、強制平倉的市場是 1730 年的大阪堂島**：建倉要存保證金（有紀錄低至 5%），每 10 天結算、虧損方補繳，價格偏離超過一定幅度時所有部位強制平倉。

## 四個候選背景

| 背景 | 機制貼合度 | 商品 | 可做成消息卡的真實事件 |
|---|---|---|---|
| 中世紀歐洲（約 1300） | 低 | 小麥、羊毛、鹽、海煤（sea coal）、胡椒 | 1315–17 大饑荒，小麥價漲到 2.5 倍以上；1306 倫敦禁燒海煤；1337 Edward III 禁止羊毛出口 |
| 1600 年代阿姆斯特丹 | 中 | 鯡魚、穀物、鯨油、香料、鬱金香 | 1610 賣空禁令；1637 鬱金香崩盤；1642 捕鯨壟斷被打破 |
| 1700 年代大阪堂島 | **最高** | 只有米（可用不同藩、不同等級的米代替） | 1732 享保饑荒米價漲約 7 倍；1733 打毀米商騷亂；1837 大塩平八郎之亂 |
| 鍍金時代芝加哥（約 1888） | 高 | **玉米、小麥、原油、黃金都有**；天然氣當時不交易，可換成煤 | 1888 Old Hutch 軋空九月小麥；1897–98 Leiter 囤積小麥，被 Armour 破冰運麥擊潰；1869 黃金黑色星期五 |

**建議**：要保留現在的商品清單，選芝加哥；要機制最真實，選堂島。

## 尚未核實

- 1865 年 CBOT 就收「每日」變動保證金的說法，找不到原始出處。
- Old Hutch 的身分：Benjamin P. Hutchinson 與其子 Charles 的資料互相矛盾。
- 泥炭、牛脂、橄欖油、中世紀鯨油的交易情形沒有查。
