Café, Illustrated

你會做什麼
點圖上的編號，聽單字、看例句。「Find it」模式是聽到單字後去圖上找。下面把整個點餐流程拆成 6 步，每步列出店員會說的話和你可以回的話。
練到的

限制

Demo B · 句型

Café Phrase Map

你會做什麼
21 個句型，依「你想做的事」分成六組（點東西、改做法、內用外帶、付錢、問問題、出狀況）。點空格下面的字就換詞並播放整句。Recall 模式給你中文，你說英文，計時並自評，想不起來的句型下次會更常出現。
練到的
把整句當成一塊記起來，要用時直接拿出來，開口比較快。
限制
題目是固定的，不練臨場反應。對方說了意料之外的話，這裡練不到。

Demo C · 任務對話

Barista Missions

你會做什麼
拿到一個任務（例如外帶一杯燕麥奶拿鐵、刷卡），跟 Claude 扮的店員自由對話。每個任務有一個意外（燕麥奶沒了、刷卡機壞了、店員誤會你）。過程中不糾正你；店員聽不懂時會像真人一樣反問。結束後給最多三個「最小修改」和下一步建議。
練到的
在真實流程裡把意思講清楚、臨場應變。店員有沒有聽懂，就是最直接的回饋。
限制
要在 claude.ai 裡開才能用，每句都會用到你的 Claude 額度。店員的聲音是瀏覽器內建語音，品質看你的裝置。

我的看法

你說想「針對某個情境學習英語表達」，目標是正確表達、講得順。三個裡最貼近這個目標的是 C，因為只有它逼你在情境裡自己組句子，而且聽不懂就會被反問。

不過 C 單獨用會有一個問題：不知道怎麼講的時候只能卡住。B 剛好補這個洞，它就是 C 裡按 Hint 時給你的那些句型。A 最適合當第一次接觸新情境時的「地圖」。

所以如果要做成一套，我會建議每個情境都走這條路：

A 看圖認場景→B 背句型→C 實戰任務→C 同任務再來一次

最後一步「同一個任務再來一次」是有根據的：同樣的任務重複做，第二、三次通常會更順（見下面的 4/3/2 研究）。

查到的資料

圖解英語這類書（例如《21世紀情境式英語圖解字典》、《All-in-One 全方位情境式英語圖解字典》、《彩繪圖解英語會話》）做法很一致：一個場景畫成一張圖，物品編號對照單字，再配上該場景的會話。Demo A 就是照這個形式做的。

圖片輔助記單字：有幾篇小規模的課堂研究發現，用圖解字典教單字的組別，測驗表現比一般字典組好。這些多是單一學校、樣本小的研究，可以當參考，不算定論。

語塊（lexical chunks）：語塊指的是整串記住、整串拿出來用的字組。相關研究的主張是，用語塊講話可以減輕臨場組句的負擔，所以講得比較順。也有研究讓學生做語塊訓練後，口說流利度測驗進步。Demo B 就是照這個想法做的。

任務型教學（TBLT）與角色扮演：讓學習者為了完成一件真實的事去用語言，有研究顯示對口說有幫助，不過我找到的多是個別課堂的研究。Demo C 就是這個方向。

重複同一個任務（4/3/2）：Nation 的 4/3/2 活動是把同一段話講三次，時間越來越短（4、3、2 分鐘）。研究觀察到重複後語速變快、停頓變少。Demo C 的「再來一次」和 role-play 頁面的計時，都是參考這個。
