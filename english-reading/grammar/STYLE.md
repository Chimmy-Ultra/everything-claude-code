# 文法書：寫作規範與格式

這本書寫給一位台灣的成人學習者：多益考過 690，目標 785 以上、最好 860（金色證書），但**文法幾乎忘光了**。這位學習者讀得懂中文講解，英文例句要商業情境。這本書教的是文法本身，不是解題技巧；解題在 The Workbook 做。

## 1. 語氣與原則

- **中文講解，英文例句。** 講解用台灣繁體中文，口語、清楚、短句。英文字詞夾在中文裡時用 `<em>…</em>`。
- **問什麼答什麼。** 每一節只講一個觀念。延伸的東西放到後面的章節，不要在這一節順帶講。
- **門檻要慢慢講。** 每個觀念都有一兩個「卡住就全卡住」的點（例如：子句一定有自己的主詞和動詞）。那種「大家都知道吧」想一句帶過的地方，通常就是門檻，要用一整段講清楚。
- **用對比，不用定義。** 把對的句子和錯的句子、兩個相近的形式並排，比抽象定義有用。
- **講「拿掉會怎樣」。** 一個規則為什麼存在，先讓讀者看到沒有它句子會壞在哪裡。
- **每節用一句話收。** 讀者一週後只會記得這一句。
- **沒有字數上限，但不灌水。** 長度由觀念的難度決定。
- **不捏造關於考試的事實**：不寫「最常考」「每場考幾題」「出現率」「官方規定」之類沒有根據的話。可以說「多益會考這個」——只在你很確定時，而且不帶數字。
- 不用驚嘆號、表情符號、「讓我們」「記住」「小提醒」這類填充語。不稱讚讀者。
- 例句全部是**原創**、自然、正確的商業英文（辦公室、會議、出貨、飯店、招募……）。人名、公司名、地名都虛構。不抄任何教材或考題。
- 例句以美式拼字為準；正解在英式與美式正式書面英文都要對。

## 2. 共用術語（全書一致；第一次出現時照這裡的意思講）

| 術語 | 意思 |
|---|---|
| 詞性 | 名詞、動詞、形容詞、副詞、介系詞、連接詞、代名詞 |
| 主詞 | 做動作或被描述的人事物；回答「誰／什麼」 |
| 動詞 | 句子的核心；一個句子（子句）一定要有一個有時態的動詞 |
| 受詞 | 動作的對象（approved **the budget**） |
| 補語 | 說明主詞是什麼、怎麼樣（The report is **late**） |
| 片語 | 一組字，**沒有**自己的主詞＋動詞（because of the delay；in the morning） |
| 子句 | 一組字，**有**自己的主詞＋動詞（because the truck was late） |
| 主要子句 | 自己就能成為一句話的子句 |
| 從屬子句 | 掛在主要子句上、不能單獨成句的子句（由 because、although、who、which、if 等帶頭） |
| 連接詞 | 後面接子句（because、although、while、unless） |
| 介系詞 | 後面接名詞或 Ving（because of、despite、during） |
| 連接副詞 | 連接兩個句子的意思，但文法上不能把兩個子句接成一句（however、therefore、as a result）；前面用句號或分號 |
| 原形 | 動詞沒有變化的樣子（go、be、submit） |
| to V | to + 原形（to submit） |
| Ving | 動詞加 -ing（submitting） |
| p.p. | 過去分詞（submitted、written） |
| 時態 | 動作的時間（現在、過去、未來）＋樣子（簡單、進行、完成） |

這張表是全書的共同語言。前面的章還沒講到的術語，後面的章用到時要一句話提醒是哪一章講的（「子句（第 3 章）」）。

## 4. 每章的格式：`chapters/<n 兩位數>-<id>.json`

```json
{
  "id": "skeleton", "n": 2,
  "title": "句子的骨架", "en": "The Shape of a Sentence",
  "lead": "這一章在講什麼、為什麼後面的章都靠它（2–4 句中文）。",
  "check": [ 小題, 小題, 小題 ],
  "sections": [
    {
      "h": "小節標題",
      "body": ["中文段落，可以用 <em>English</em>、<b>重點</b>。", "第二段"],
      "ex": [ {"en": "The new <u>manager</u> approved the budget.", "zh": "新經理核准了預算。", "note": "可省略的中文說明"} ],
      "table": {"head": ["…", "…"], "rows": [["…", "…"]]},
      "quiz": [ 小題 ],
      "takeaway": "這一節的一句話。"
    }
  ],
  "mistakes": [ {"wrong": "Despite the truck was late, …", "right": "Although the truck was late, …", "why": "中文說明"} ],
  "workbook": ["connect"]
}
```

- `check`：**開頭小確認**，3–5 題，涵蓋本章核心。頁面會說：全對可以跳過這章。所以它必須真的測到本章的門檻，不是測冷門細節。
- `sections`：4–9 節。`ex` 每節 1–5 句；`table` 與 `quiz` 可省略；`takeaway` 必填。每章的 `quiz` 合計 4–10 題，分散在各節後面，用來確認剛讀的那一節懂了沒有。
- `mistakes`：2–5 組常見錯誤，`wrong` 與 `right` 是同一句的兩個版本。
- `workbook`：讀完之後去 The Workbook 練哪些單元（id 見上表；第 2 章用 `[]`）。
- 可用的標記：`<em>`（中文裡的英文字詞）、`<b>`（重點）、`<u>`（例句裡要注意的部分）。不要用其他 HTML。

### 小題（`check` 與 `quiz` 共用）

兩種：

```json
{"type": "choose", "q": "題目（中文，可含英文句）", "options": ["…", "…", "…"], "answer": 1, "why": "為什麼（中文）"}
{"type": "tap", "q": "點出這句的主詞（可以點好幾個字）", "sentence": "The new manager of our Westbrook office approved the budget.", "answer": [0, 1, 2], "why": "為什麼"}
```

- `choose`：2–4 個選項，只有一個對。這是**理解確認**，不是多益題：問「這句的動詞是哪個」「這裡要接名詞還是子句」「這兩句哪一句對」。
- `tap`：句子以空格切成字（標點黏在字上），`answer` 是要點的字的位置（從 0 數）。用在「點出主詞／動詞／子句／關係代名詞修飾的名詞」這類題。答案要是一個清楚的範圍，不能有兩種合理的點法。
- `why` 一定要寫，講清楚判斷的方法，不只是答案。

## 5. 交稿前自查

1. `python3 check.py <檔名>` 沒有錯誤。
2. 每個英文例句自己念一遍：文法對、自然、商業情境、虛構名字。
3. 每一題只有一個答案；`tap` 題沒有第二種合理的點法。
4. 沒有使用前面還沒講的術語而不提醒。
5. 沒有「最常考」「每次都考」之類的話。
