`TSL_12_stats.csv` (word, rank, SFI, U), `TSL_12_lemmatized_for_teaching.csv`, `TSL_12_definitions.xlsx`.

The site describes the list as built from a 1.5-million-word corpus of TOEIC preparation materials
(not official ETS tests). The Workbook uses it only to choose which words to practise.
